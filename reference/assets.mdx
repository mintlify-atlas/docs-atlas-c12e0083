## Animation Timeline

Assets appear in a choreographed sequence:

1. **0-11s:** COBATAB logo sequence
   - CobatabLogo.png animates and fades
   
2. **11-17s:** RPLT logo formation
   - RPLT Icon.png fades in and repositions
   - RPLT Text.png fades in
   - Complete logo fades out
   
3. **19-21s:** Content reveal
   - frame.png (QR code) fades in at 19s
   - Requiem por la Tierra.png fades in at 20s
   - Title "PASE DIGITAL" fades in at 20.8s

## Asset Guidelines

### Image Formats
- All images use PNG format for transparency support
- No compression settings specified in code

### Responsive Sizing
- Logo images: Use `min()` function for fluid sizing
- Content images: Mix of fixed (rem) and responsive (%) sizing

### Optimization Recommendations
- Consider using WebP format with PNG fallback for better performance
- Implement lazy loading for below-the-fold images
- Ensure all images have appropriate alt text for accessibility

### Accessibility
- All images include descriptive alt text
- Decorative images should use empty alt attributes
- Consider adding ARIA labels for complex graphics
