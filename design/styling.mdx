## Base Styles

### HTML Foundation

```css styles.css
html{
    font-size: 62.5%;
    box-sizing: border-box;
}
```

<Accordion title="Why 62.5% font-size?">
Setting `font-size: 62.5%` on the HTML element makes `1rem = 10px` (assuming default browser font size of 16px).

This simplifies rem calculations:
- `1.6rem` = 16px
- `2.2rem` = 22px
- `3rem` = 30px

This maintains accessibility (users can still change browser font size) while making development easier.
</Accordion>

### Box Model Reset

```css styles.css
*, *:before, *:after {
  box-sizing: inherit;
  padding: 0;
  margin: 0;
}
```

Applies consistent box-sizing and removes default padding/margins from all elements.

### Body Typography

```css styles.css
body{
    font-size: 1.6rem;
    font-family: "Poppins", sans-serif;
}
```

**Base font size**: 16px (1.6rem)  
**Font family**: Poppins (requires external font import)

## Responsive Design Patterns

### The `min()` Function

Requiem for Earth uses CSS `min()` extensively for fluid, responsive sizing without media queries.

#### Logo Sizing

```css styles.css
.cbtlogo{
    width: min(28rem, 40%);
}

.lgicon, .lgtext{
    width: min(30rem, 40%);
}
```

**Logic**: Element takes the **smaller** of:
- Fixed size (28rem/30rem)
- Percentage of container (40%)

<Accordion title="How min() Works">
On a **large screen** (e.g., 1920px wide):
- 40% = 768px
- 28rem = 280px
- Element uses **280px** (smaller value)

On a **small screen** (e.g., 375px wide):
- 40% = 150px
- 28rem = 280px
- Element uses **150px** (smaller value)

This creates responsive sizing without breakpoints.
</Accordion>

#### QR Code Sizing

```css styles.css
.contqr img{
    width: min(30rem, 60%);
    border: var(--tertiary) 1.6rem solid;
}
```

Uses 60% (instead of 40%) for larger display on smaller screens.

#### Content Padding

```css styles.css
.gen-cont{
    padding: min(2rem, 4%) min(3rem, 6%);
}
```

**Vertical padding**: min(20px, 4%)  
**Horizontal padding**: min(30px, 6%)

Padding scales proportionally on small screens while capping at fixed values on large screens.

## Layout Utilities

### Full Viewport Blocks

```css styles.css
.block{
    width: 100vw;
    height: 100vh;
}
```

Applied to COBATAB and LOGO sections to fill the entire viewport during their animation phases.

### Absolute Centering

```css styles.css
.center-abs-elem{
    top: 0;
    left: 0;
    right: 0;
    bottom: 0;
    margin: auto;
    text-align: center;
}
```

**Usage**: Centers logos, icons, and text within absolutely positioned sections.

<Note>
Requires `position: absolute` on the element and `position: relative` on the parent.
</Note>

### Main Container

```css styles.css
main{
    position: relative;
}
```

Establishes positioning context for absolutely positioned child sections (COBATAB, LOGO).

## Styling Best Practices

### Maintainability Tips

1. **Use CSS variables**: All colors reference `:root` variables
2. **Responsive by default**: `min()` replaces most media queries
3. **Consistent spacing**: All spacing uses rem units (based on 10px)
4. **Shared animations**: `last-anim` used by multiple elements

### Customization Guide

<Accordion title="Change Color Scheme">
```css
:root{
    --primary: #your-color-1;   /* Reserved */
    --secondary: #your-color-2; /* Subtitle badges */
    --tertiary: #your-color-3;  /* Footer & QR border */
}
```
</Accordion>

<Accordion title="Adjust Animation Speed">
```css
/* Speed up by 2x (divide durations and delays by 2) */
.cbtlogo { animation: cbt-an1 1.5s 1s forwards ease; }
.cbttext { animation: cbt-an2 2.5s 2s forwards ease; }
/* ... update all animation timings */
```
</Accordion>

<Accordion title="Modify Responsive Breakpoints">
```css
/* Make logos larger on small screens */
.cbtlogo { width: min(28rem, 60%); } /* was 40% */

/* Adjust content padding */
.gen-cont { padding: min(3rem, 5%) min(4rem, 8%); }
```
</Accordion>
